## 可用流程

从首页或导航进入 [真实面试复盘](http://localhost:3000/interview-reviews)，选择“记录一次面试”。日期默认北京时间当天，只填写一个实际问题即可保存；岗位 / 面试名称、备注、当时的回答摘要、五类卡点、说明、下一次改进及关联题均可之后补充。每次最多 20 个问题，已保存问题保留 ID 和顺序，新问题追加；只允许移除尚未保存的新问题。

列表每页 10 条，按面试日期、创建时间和 ID 稳定倒序；非法页码明确提示，越界页码夹到末页。详情与折叠编辑可回看当次原话和个人记录。题库没有收录的问题也可独立保存，不创建公共题。

手动搜索启用题并关联后，详情提供参考、个人回答卡、关联后的正式回答和补练入口。关联时保存题干快照，改公共题、停用或重新导入不会覆盖面试原话与旧快照。同一公共题可以关联多次面试，各次原话、个人字段及补练基线独立。复盘卡点保存在当次问题中，不自动写入 W3 长期卡点。

## 补练与统计口径

详情区分“未关联题库”“待正式补练”“关联题已停用”“关联后已正式练过”。关联时保存 `linkedAt` 与 `practiceAfterEventId`：只计算当前用户、当前关联题、时间不早于关联时间且 ID 大于当时已有事件最大 ID 的 `review_events.kind='practice'`。时间和事件 ID 同时核对，排除同毫秒旧回答。普通编辑保持原基线，取消或更换关联重新开始跟进。

待补练问题按记录顺序、题目 ID 去重，形成 3 / 5 题固定队列，不足时显示实际数量，停用题不入队。单题也可明确进入普通练习。只有用户在普通练习点击“完成本题”才增加正式事件、次数和复习安排；记录复盘、编辑、关联、读取详情和打开补练都不修改这些记录。“练过”不能据此推断已掌握或该次面试合格。

统计页新增“范围内面试复盘问题”：已关联复盘问题、关联后正式练过、待正式补练。只统计当前共享范围中的启用关联题，按复盘问题记录计数；同题多次面试分别计数。通过独立聚合与 EXISTS 判断补练，避免正式事件多次或多个关联放大计数。原正式覆盖仍按独立题目计算，与复盘记录数分开。

## 持久化、接口与恢复

新增三表：

| 表                           | 保存内容                                                              |
| ---------------------------- | --------------------------------------------------------------------- |
| `interview_reviews`          | 面试日期、名称、备注、用户、revision、创建 requestId 与原始规范化请求 |
| `interview_review_questions` | 原问题、顺序、独立摘要 / 卡点 / 改进、可空关联、题干快照与补练基线    |
| `interview_review_actions`   | 修改 requestId 与规范化请求，支持重试和迟到重试                       |

复合外键校验父记录归属，关联题使用 restrict。创建按用户与 requestId 幂等，后续编辑不改变原创建请求；修改在事务内锁复盘、匹配 revision，并保存请求 ledger。重复或迟到重试不重复修改，不同内容的同 ID 或版本冲突返回 409，当前服务器记录供本人核对。新问题与请求记录一并写入，失败整体回滚。

| 入口                                               | 行为                                          |
| -------------------------------------------------- | --------------------------------------------- |
| `/interview-reviews`、`/new`、`/[id]`              | 列表、新建、详情与编辑                        |
| `POST /api/interview-reviews`                      | 创建，首次 201、幂等重试 200                  |
| `GET /api/interview-reviews/[id]`                  | 当前用户只读详情                              |
| `PUT /api/interview-reviews/[id]`                  | revision 与 requestId 修改                    |
| `GET /api/interview-review-question-options?q=...` | 搜索启用题，最多 20 条，仅返回 ID、题干与分类 |

保存后的资料由服务端恢复。未保存编辑使用独立草稿键 `practice:note:interview-review:v1:{create|id}`，与普通练习、W3 和 W5 隔离。暂时失败保留原请求重试；响应丢失后刷新可恢复同一请求。另一页面的 storage 事件不覆盖当前本地文字。409 后可核对并采用服务器记录，或按问题 ID 合并本地内容并保留服务器新增问题。浏览器存储不可用时当前页面仍保留文字并允许服务端保存，刷新恢复不作承诺。
