## 内容修订

30 道核心题补全口头回答，解释 token 的切分、词表编号等机制，继续由核心内容单一来源生成详情和练习答案。70 道基础题扩充结论、解释和具体情境。

327 道扩展题分别补充本题机制和示例；不再把同主题的共享说明直接当作每题讲解。Few-shot 成本题改为固定模型、样本和判分规则，比较 0 / 2 / 4 个示例的成功率与每成功任务费用；类型注解题补充外部 JSON 的字符串值、运行时解析与业务约束的区别。

143 道原普通题补充逐题例子，移除分类级重复的“岗位场景中的验证”。输入与输出 token 成本题区分输入预填充的并行计算、输出逐步解码和供应商定价，避免用计算机制直接推导价格。

100 道简历题补充完整短答、具体机制和明确的假设场景。五工具边界题解释材料事实、规则结果、制度依据与流程出口之间的数据关系，原有源码字段、日志和脱敏材料准备要求保留在证据准备部分。假设情境不计为本人新增经历；本次没有重跑 VendorGuard 或实习项目验证。

重复检查按“同标题、清理 Markdown 后正文完全相同、正文至少 40 个有效字符”归组。审查脚本列出的主讲解和示例标题重复组均为 0；共享主题背景仍有 124 组、涉及 437 题、单组最多 5 题，统一标为“主题背景（补充）”。这不代表所有文本完全无重复，短答也可能复用本题后续讲解中的表述。
