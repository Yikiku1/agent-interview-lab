## 可用流程

首页“查看目标进度”进入 [学习统计](http://localhost:3000/stats)。默认使用已保存的当前目标；未配置目标时查看全部启用题，不自动创建目标。页面明确范围、正式练过与未练题数、个人卡、证据填写、未解决卡点和本人自评分布。

“查看其他范围的进度”复用题库筛选，支持预设、项目、优先级、回答性质和原分类、难度、状态、搜索。筛选只影响当前查看，不修改训练目标；“恢复当前目标”返回默认范围。非法、重复、未知及冲突条件显示修正入口。

未练列表按题目 ID 稳定排序，每页 12 题，提供本页 3/5 题固定队列入口。分页保留查看范围；仅携带页码时继续使用当前目标，越界页码夹到最后有效页。空范围不展示覆盖率或练习入口，全部正式练过时提供巩固提示。卡点按类型显示记录数并链接到对应筛选和去重补练。

## 统计口径与实现

| 指标       | 实际口径                                                                            |
| ---------- | ----------------------------------------------------------------------------------- |
| 范围题数   | 共用筛选条件内的启用题；当前无目标/通用核心为 670，简历重点 100，基础补齐 22        |
| 正式覆盖   | 当前用户在范围内至少有一次 `kind=practice` 事件的独立题数；重复完成、重试不增加覆盖 |
| 未正式练过 | 范围题数减正式覆盖；只自评、看答案、保存卡片或观察仍属于未练                        |
| 本人自评   | 范围内最新进度的掌握/模糊/不会/未标记，与正式覆盖分开                               |
| 个人回答卡 | 范围内已有卡记录的独立题数，四字段均空仍算建立卡片                                  |
| 证据已填写 | 卡片 `evidence.trim()` 非空，包含粘贴的 Unicode 空白处理；表示本人填写状态          |
| 未解决卡点 | 当前用户、启用范围内未解决记录数，按类型计数；同题多条记录可重复计，补练按题去重    |

通用核心预设沿用共享范围契约，统计全部启用题；首页 30 题核心路径仍是推荐路径的范围。页面显示“通用核心 · 全部启用题”，避免混用分母。停用题同时退出分子和分母，原历史、卡片和观察继续保留可读。

`src/lib/scope-progress.ts` 在只读、repeatable read 事务内读取目标、范围、计数和分页，保证同一快照。正式事件用 `EXISTS`，个人卡和卡点独立聚合，避免联表放大覆盖。未练查询只取题目信息与自评，不携带公共长答案。`scope-progress-contract.ts` 管理严格查询解析和范围标签，`scope-progress-panel.tsx` 管理展示；题库筛选仅增加可选表单地址、隐藏字段与重置入口，原默认行为保留。

本批次不修改 Schema、冻结迁移、公共题目、正式提交、自评保存、草稿或固定队列契约。无需迁移个人库。
